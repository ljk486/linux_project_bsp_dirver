# Day 06（2026-09-27）：`create_table_entry` 逐句精读 + GNU 汇编宏语法

> 源码：`arch/arm64/kernel/head.S:165`（Rockchip 4.19）。
> 配置前提：4KB 页（PAGE_SIZE=4096）、VA_BITS=48、4 级页表（L0~L3，每级 512 项）。
> `PMD_TYPE_TABLE = 3 << 0`（pgtable-hwdef.h:130），即低两位置 `0b11` = "目录项"。

## 一、语法基础（第一次接触汇编宏必看）

`.macro 名字, 形参1, 形参2, ...` 定义宏，`.endm` 结束；宏体内 `\形参名` 引用参数。
**宏是编译期纯文本替换**，不占运行时。真实调用：

```asm
create_table_entry x0, x3, EXTRA_SHIFT, x4, x5, x6
```

替换后宏体里 `\tbl→x0, \virt→x3, \shift→EXTRA_SHIFT, \ptrs→x4, \tmp1→x5, \tmp2→x6`。
所以宏参数能传 `EXTRA_SHIFT` 这种编译期常量——它只是文本。

六条指令（目标寄存器在前）：

| 指令 | 例 | 等价 C |
|---|---|---|
| add | `add x5, x0, #4096` | `x5 = x0 + 4096` |
| sub | `sub x4, x4, #1` | `x4 = x4 - 1` |
| orr | `orr x6, x6, #3` | `x6 |= 3` |
| and | `and x5, x5, x4` | `x5 &= x4` |
| lsr | `lsr x5, x3, #39` | `x5 = x3 >> 39`（无符号） |
| str | `str x6, [x0, x5, lsl #3]` | `*(u64*)(x0 + x5*8) = x6` |

`#` = 立即数；`PAGE_SIZE` 是 #define 的 4096，编译期代入。
`[基址, 索引, lsl #3]` = 变基寻址：地址 = 基址 + 索引×8，就是 C 数组 `tbl[i]` 的硬件版（PTE 8 字节所以 ×8）。

## 二、逐句精读（附数字演练）

宏的目的：**在当前目录页的某一格登记"下一级目录页在哪"，并把游标挪过去**。
八行分三组：①②③备"写什么"，④⑤⑥算"写到哪"，⑦写入，⑧挪游标。

演练设定：目录页地址 T，虚拟地址 `0x0000_0080_0000_0000`，shift=39（L0 层），ptrs=512。

```asm
add\tmp1, \tbl, #PAGE_SIZE
```
`tmp1 = T + 4096`。下一级页表页**不需要分配**——链接脚本预留了连续一块，
规则就是"当前页的下一页"。启动早期没有内存分配器，只能这样约定。

```asm
phys_to_pte \tmp2, \tmp1
```
宏套宏（pgtable.h），物理地址→PTE 格式。48VA 配置下近似恒等，先当 `tmp2 = tmp1`。

```asm
orr\tmp2, \tmp2, #PMD_TYPE_TABLE
```
`tmp2 = (T+4096) | 0b11`。PTE 最低两位是"类型"域：00=invalid，01=页/块，
11=指向下一级目录表。MMU 走到这项看低两位就知道"继续查下一本目录"。

```asm
lsr\tmp1, \virt, #\shift
```
`tmp1 = 0x0080_0000_0000 >> 39 = 256`。把虚拟地址里**本级用的 9 位**移到最低位。
39 = 12(页内偏移) + 9×3（下面三层各 9 位索引），由宏参数传入。

```asm
sub\ptrs, \ptrs, #1
and\tmp1, \tmp1, \ptrs
```
`tmp1 = 256 & 511 = 256`。511 = 2⁹−1 = 九个 1。`x & (2ⁿ-1) == x mod 2ⁿ`，
但与门一周期、除法几十周期——和 C 里 `x & (size-1)` 同一个 trick。
这两行合起来 = "取第 4 步结果的低 9 位 = 本级格号"。

```asm
str\tmp2, [\tbl, \tmp1, lsl #3]
```
`*(u64*)(T + 256×8) = (T+4096)|0b11`，即 `T[256] = ...`。
写入前 T[256]=0（invalid，fault）；写入后 MMU 可沿它找到下一级目录。**宏的核心目的就这一行。**

```asm
add\tbl, \tbl, #PAGE_SIZE
```
游标挪到下一级目录页（T+4096），调用方接着用它填下一层，逐级递进到 L3。

## 三、与叶子层的分工

| | 目录项（本宏 / map_memory 前三级） | 叶子项（L3 populate_entries） |
|---|---|---|
| 内容 | 下一级**目录页**地址 | 真实**物理页框**地址 |
| 属性位 | PMD_TYPE_TABLE (0b11) | flags（有效+读写+普通内存） |
| 意义 | 只搭骨架，不映射内存 | 虚拟→物理映射真正建立 |

调用前后对比：`T[256]: 0(invalid) → (T+4096)|0b11`，MMU 的查表之路从断到通。
